# IdeaLab

**Твоя идея. Твой бизнес. Твоя история.** Уютная экономическая игра про одну кофейню: Telegram Mini App, бот и отдельная честная браузерная демонстрация. Русский интерфейс, мобильная навигация, живая изометрия PixiJS, серверные смены по 5 минут, сохранение и магазин косметики за Stars.

## Запуск локальной демонстрации

Нужен **Node.js 24 LTS**. Ключи и PostgreSQL для демо не нужны.

```bash
npm ci
npm run db:generate
npm run dev
```

Открой локальный порт **3000** в браузере. Без BOT_TOKEN разработка автоматически включает отдельный деморежим; на экране всегда видна надпись «ДЕМО». Состояние — `.data/idealab.sqlite`, постоянный ключ локальных сессий — `.data/demo-session.key`. Не удаляй эти файлы для обновления приложения. Они не попадают в Git. В production демонстрация запрещена проверкой при старте.

Для сборки и проверки:

```bash
npm run build
npm test
npm run test:economy
npm run browser:install
npm run test:visual
```

Браузерная проверка требует работающего `npm run dev`. Для установленного системного Chromium можно задать CHROMIUM_PATH. Снимки и результаты — в `artifacts/`. Интеграционный PostgreSQL-тест включается через TEST_DATABASE_URL к отдельной тестовой БД; он не должен указывать на production.

## Что работает

- Поэтапное сохраняемое обучение, название, машина, первый гость/выручка, бесплатное улучшение и пропуск.
- Меню из пяти позиций, три стратегии, шесть сотрудников, назначение и обучение, запасы, отчёты, журнал монет, восстановительная смена.
- Серверная воспроизводимая экономика. Начатая смена завершается после выхода и перезапуска сервера. Повторная операция не начисляет деньги снова.
- Панорамирование/масштаб, сортировка по глубине, движение гостей по сетке, карточки, оформление с серверной проверкой и складом. Доступны обычные HTML-кнопки и поля координат.
- 12 улучшений, 30 событий, три цепочки, три визуальные главы, достижения и коллекция знакомых лиц.
- Пять товаров, предпросмотр без списаний, применение своих наборов, история покупок, Plus, источники прав и управляемые возвраты. В демо Stars не списываются.
- Бот /start /help /support /paysupport /terms, защищённый webhook, opt-in уведомления. Поддержка действительно сохраняет обращения и позволяет администратору отвечать.
- Кабинет для заданных Telegram ID: игроки, баланс, валютный журнал, заказы, оплаты, права, возвраты, обращения, фактические счётчики аналитики и аудит.
- Настройки звука, вибрации, анимаций и качества. Необязательный ИИ-наставник с квотами и шаблонной заменой.

Скопируй `.env.example` в `.env`, внеси секреты **локально или в защищённом хранилище развёртывания**, не в чат и не в Git. Docker Compose поднимает PostgreSQL и production-приложение. Реальные BOT_TOKEN, домен/HTTPS, маршрут поддержки и Telegram test environment необходимы для внешней проверки. Реальные платежи в этой поставке не проводились.

Каталоги и формулы — `shared/content.ts`, серверные правила — `server/game.ts`, Prisma-схема и SQL-миграция — `prisma/`. Цены новых счетов меняются через конфигурацию в коде; редактирование каталога из кабинета пока не предусмотрено. Старые счета сохраняют сумму.

Это первая цельная версия одной кофейни. Прочитай ограничения в QA перед публичным запуском: локальные проверки не равны сертификации в Telegram или нагрузочному тестированию production.
