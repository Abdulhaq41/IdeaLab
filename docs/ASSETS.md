# Происхождение ресурсов

Все игровые изображения оригинальные, созданные для IdeaLab. Реальные бренды и чужие персонажи не использовались.

Генератор изображений OpenAI:

- `cafe-story.png` — иллюстрация кофейни для сюжетных карточек.
- `characters-atlas.png` — 8 согласованных персонажей (4×2, 384×512): Тимур, Лола, Камол, Сара, Азиз, Вера, Амина, Рустам. Один ресурс используется и в сцене, и для портретов, кадрирование задаётся кодом.
- `objects-atlas.png` — кофемашина, стойка, столик, кресло, растение, лампа, луна и ваза (4×2, 384×512), прозрачный фон.

Собственные векторные ресурсы, созданные кодом (`scripts/assets.py`, `scripts/event-art.py`): логотип, шесть визуально разных типов гостей, запасные портреты/спрайты, кофемолка, холодильник, витрина, акустика, книги, вывеска, статуэтка, товары магазина и 30 сюжетных иллюстраций. Пол, стены, окно, свет, сетка и тени рисуются Pixi Graphics. SVG служат также резервом при недоступном атласе. Они не заимствованы из сторонних библиотек.

Иконки интерфейса: собственные SVG-пути в `client/src/Icon.tsx`. Основные ресурсы не заменены эмодзи. Текст, названия, цифры и цены — HTML/Pixi, не часть сгенерированных изображений.

Звук — оригинальный синтез через Web Audio в `client/src/audio.ts`: тихий гармонический фон, приготовление, подтверждение, завершение. Внешних аудиозаписей и музыки нет. Запуск после пользовательского жеста. Музыка и эффекты имеют разные сохраняемые настройки.

Ограничение художественной поставки: процедурная ходьба вместо отдельных покадровых циклов; главы используют одну комнату с меняющимися деталями. У каждой истории есть своя SVG-композиция, а не 30 отдельных сгенерированных полотен.
