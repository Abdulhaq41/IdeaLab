# Подключение @IdeaLabGame_bot

Токен получен от владельца бота и сохранён только в локальном ignored-файле `.data/telegram.env` с правами 600. SESSION_SECRET и WEBHOOK_SECRET сгенерированы и находятся там же. Значения не включены в код, документацию, Docker build context или архив исходников. Встроенная защищённая поддержка использует настоящий адрес этого бота с параметром `start=support`.

Текущий результат подключения: **не подключён**. Исходящий запрос к api.telegram.org блокируется действующим сетевым прокси (403). Проверка getMe из подготовленного скрипта также не прошла; валидность токена пока не подтверждена. Настройки Bot API не изменены.

Домены api.telegram.org, telegram.org, core.telegram.org уже сохранены в черновике облачной среды, но в работающей политике их нет. Для продолжения владелец среды должен проверить, сохранить и применить/опубликовать этот черновик через настройки среды. Изменение локального network-policy.json не открывает доступ и не используется.

После разрешения доступа к API:

```bash
npm run bot:connect -- --metadata-only
```

Команда проверит принадлежность токена ожидаемому боту и настроит русские имя, описание и пять команд. Токен в журнал не выводится. Это ещё не запускает Mini App или обработку входящих сообщений.

Для Mini App нужен публичный HTTPS-сервер. **Покупать собственный домен для теста не требуется**: можно использовать адрес тестового хостинга или поддерживаемого временного HTTPS-туннеля. В текущей облачной среде не предоставлен инструмент публичной публикации/туннеля; выдуманный адрес или localhost не устанавливаются в Telegram.

Полное подключение выполняется после безопасной настройки PUBLIC_URL, PostgreSQL и запуска сервера с Telegram-авторизацией:

```bash
npm run bot:connect
```

Скрипт проверит публичный `/health` и режим Telegram, сохранит существующий чужой webhook, если он обнаружится, и настроит меню/webhook только для подходящего сервера. Для просмотра браузерного demo без домена и без настоящих платежей остаётся `npm run dev`; его нельзя выдавать за production-авторизацию или тест Stars. Игровые инструкции — в README.md.
