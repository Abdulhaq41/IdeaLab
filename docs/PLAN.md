# IdeaLab: рабочий план

1. Серверный агрегат кофейни, атомарные операции, журнал денег, обучение, смены и отчёты; SQLite только для demo, PostgreSQL для production.
2. React UI + PixiJS изометрия, сетка и серверная проверка пути, синхронная визуализация событий.
3. Каталог из 12 улучшений, 6 сотрудников, 30 событий и три сюжетные цепочки.
4. Оригинальные графические ресурсы, процедурные движения и Web Audio.
5. grammY bot, XTR invoices, pre-checkout, atomic successful_payment, возвраты с сохранением источников прав.
6. Административные операции, аналитика, тесты безопасности/экономики, мобильная проверка и инструкции поставки.

Структура: shared — типы, контент и схемы; server — экономика, хранилище, Telegram, платежи и HTTP; client/src — UI, сцена и звук; public/art — оригинальные ресурсы; prisma — production схема/миграция; tests — критические проверки; docs — эксплуатация.

Не включать демонстрационный обход авторизации в production. Не выдавать товары по ответу браузера. Не менять начисленную часть смены. Не обещать результатов непроведённых внешних тестов.
