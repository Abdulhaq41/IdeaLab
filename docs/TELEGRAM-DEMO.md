# Посмотреть IdeaLab в Telegram с компьютера Windows

Можно [скачать готовый файл запуска](https://raw.githubusercontent.com/Abdulhaq41/IdeaLab/main/downloads/IdeaLab-Telegram.zip), распаковать его содержимое в существующую папку IdeaLab рядом с package.json и открыть start-telegram.cmd. Он использует тот же проверенный скрипт, а при отсутствии Cloudflare Tunnel предложит установить официальный пакет через winget.

Собственный домен и PostgreSQL для этого теста не нужны. Компьютер с игрой должен быть включён и иметь доступ к Telegram API и Cloudflare. Это обычный Telegram-бот с явно обозначенным browser demo, **не Telegram Stars test environment и не production**. Все покупки имитируются, настоящие pre-checkout-запросы отклоняются.

1. Установи официальный клиент Cloudflare Tunnel через Windows Package Manager:

   ```powershell
   winget install --id Cloudflare.cloudflared -e
   ```

2. После установки открой **новое окно PowerShell** в папке IdeaLab. В проекте уже должны быть выполнены `npm ci` и `npm run db:generate`.

3. Если скачанный ранее архив ещё не содержит `scripts/telegram-demo.ts`, загрузи только новый файл:

   ```powershell
   Invoke-WebRequest -UseBasicParsing -Uri "https://raw.githubusercontent.com/Abdulhaq41/IdeaLab/main/scripts/telegram-demo.ts" -OutFile ".\scripts\telegram-demo.ts"
   ```

4. Запусти:

   ```powershell
   node --use-env-proxy --import tsx scripts/telegram-demo.ts
   ```

   В свежем клоне репозитория также работает `npm run telegram:demo`.

5. Вставь токен **только в скрытый запрос локального терминала**. Символы при вводе не отображаются. Токен не нужно присылать в чат или добавлять в исходники. Ожидается `@IdeaLabGame_bot`; другой бот допускается только при явно заданном `IDEALAB_PREVIEW_BOT` с его username. Для повторного ввода нового ключа добавь `--new-token`.

6. Дождись сообщения `ГОТОВО`. Открой `@IdeaLabGame_bot` в приложении Telegram, отправь `/start`, нажми **«Открыть IdeaLab · демо»**.

## Что делает запуск

- Проверяет токен и наличие существующего webhook. Рабочий webhook не удаляется. Для занятого другим сервисом бота нужен отдельный тестовый бот.
- Собирает интерфейс и запускает отдельную демонстрацию на порту 3001. Ранее запущенный `npm run dev` на 3000 можно оставить работающим.
- Публикует только собранный `dist` через временный `https://…trycloudflare.com`. Vite dev server, `.data`, исходники и секретные файлы через туннель не обслуживаются.
- Не передаёт токен, production DATABASE_URL, админские ID и ключ ИИ веб-серверу. Прогресс этого теста хранится отдельно в `.data/telegram-preview.sqlite`.
- Проверяет по публичному HTTPS адрес `/health`, `demo=true` и создание демосессии, затем устанавливает кнопку меню бота и запускает обработку команд через long polling.
- Сохраняет локальный токен в ignored-файле `.data/telegram-preview.env`. Ключ не включён в Git или ZIP. Операции этого бота никогда не выдают настоящие оплаченные товары.

## Остановка и ограничения

Оставь окно запуска открытым. Ctrl+C останавливает только созданные им сервер и туннель и возвращает прежнюю кнопку меню, если её не изменил кто-то другой. Ранее отправленные сообщения с временной кнопкой останутся в чате; их адрес перестанет работать после остановки. В случае внезапного завершения процесса старый адрес можно сбросить через BotFather или заменить следующим запуском.

Адрес меняется при каждом запуске; новая ссылка может создать новую браузерную демосессию. Покупки и прогресс этого теста не переносятся в production. Для постоянной доступности нужны хостинг и полное подключение из DEPLOYMENT.md.

Проверено локально: TypeScript, сборка, изоляция окружения/загрузки `.env`, обработчик `/start`, отказ настоящих платежей и защита восстановления меню. Живое подключение Cloudflare/Telegram выполняется на компьютере пользователя; в облачной среде API Telegram блокируется сетевой политикой. Если cloudflared или Telegram недоступны, проверка HTTPS не отключается и меню не выдаётся за успешно подключённое.
